    The Canonical WETH Contract Address

    The WETH contract address on Ethereum mainnet is 0xC02aaA39b223FE8D0A0e5C4F27eAD9083C756Cc2, the contract commonly called WETH9. It was deployed once in December 2017 and has never changed; every wallet, DEX, and lending market that touches Wrapped Ether on mainnet points at this same address. The contract is an ERC-20 token with the symbol WETH and 18 decimals, matching native ETH's precision exactly. Its defining property is a one-to-one ETH reserve: each WETH token in existence is backed by one ETH locked in the contract, which is why its on-chain ETH balance tracks the total WETH supply at all times. You can open the address on Etherscan and read that reserve directly.

    Why the address is case-mixed

    The mix of upper and lower case in 0xC02aaA39b223FE8D0A0e5C4F27eAD9083C756Cc2 is an EIP-55 checksum. Each letter's case encodes a verification bit, so a wallet that supports checksums can detect a mistyped character before you send anything. An all-lowercase version of the same address is still valid and resolves to the identical contract, but the checksummed form is the one to copy when you can.

    WETH9 is immutable

    The WETH9 contract has no admin key, no proxy, and no upgrade path. The code that runs today is the same code deployed in 2017, which is part of why it became the ecosystem standard — there is no governance process that could change its behavior or redirect its reserve.

    What WETH Is and Why It Has a Contract

    Native ETH predates the ERC-20 token standard and does not implement its interface, so it cannot be handled by contracts that expect approve(), transferFrom(), and the other ERC-20 functions. WETH exists to close that gap: it is a token wrapper that lets ETH be treated like any other ERC-20 inside DeFi. The contract accepts ETH through its deposit() function and mints an equal amount of WETH to you, and it returns ETH through withdraw() by burning the WETH you send back. Because those two functions are the only ways supply changes, the backing stays exact and the contract never needs an external price feed.

    Deposit and withdraw

    Sending ETH to the contract — or calling deposit() — mints WETH one-for-one, and calling withdraw(amount) burns WETH and releases the same amount of ETH. These are the only mint and burn paths, so no WETH can exist without ETH locked behind it.

    One contract, reused everywhere

    Rather than each application issuing its own wrapped ETH, the ecosystem converged on a single shared WETH contract per chain. That shared address is what makes WETH liquid: a token held from one app is the exact same asset another app recognizes, with no bridging or conversion between versions.

    How to Verify a Contract Address on Etherscan

    Before you trust any address that claims to be WETH, confirm it against the block explorer for that chain. A verified token page on Etherscan shows the contract's name, symbol, decimals, holder count, and published source code, and a genuine WETH page will show an ETH reserve roughly equal to the token's market cap. The checks below separate a real token contract from an impostor that merely copied the name.

    Read the token page, not a search result

    Open the address directly as etherscan.io/token/ plus the address rather than trusting a name search, since many copycat tokens share the string "WETH". The URL you land on should contain the exact checksummed address you intend to use.

    Why addresses differ per chain

    Each chain is a separate state machine with its own deployment history, so a contract on Ethereum has no presence on Arbitrum unless it is deployed there independently. The WETH on each rollup is backed by that chain's own ETH, which is in turn bridged from mainnet.

    Match the address to the network

    A wallet connected to Polygon will not recognize the mainnet WETH address, and pasting an Arbitrum address while on Base points at an unrelated or nonexistent contract. Always confirm which chain your wallet is on before adding or sending WETH by address, and remember that bridging ETH between chains produces WETH at the destination chain's own contract rather than carrying the mainnet address along with it.

    How to Add WETH to a Wallet by Address

    If WETH does not appear automatically in your wallet after a swap or bridge, you can add it manually using the contract address for your current chain. The steps are the same in most wallets.
    • Confirm which network your wallet is connected to and copy the matching WETH address from the table above.
    • Open your wallet's token list and choose Import tokens or Add custom token.
    • Paste the WETH contract address into the address field.
    • Let the wallet auto-fill the symbol (WETH) and decimals (18), or enter them if prompted.
    • Confirm, and your WETH balance will display alongside your other tokens.

    When the symbol does not auto-fill

    If the symbol and decimals stay blank, the address is either on the wrong chain or not the genuine token contract. Re-check the network and the address rather than typing the fields in by hand, since a wallet that cannot read the contract cannot track the balance correctly.

    Avoiding Fake or Scam Token Contracts

    Because anyone can deploy a contract and label it WETH, scam tokens that reuse the name and logo are common, especially in airdrops and in search results that are not the official explorer page. The real WETH address never changes and is always the one published by the explorer and major aggregators, so the safest habit is to copy it from a source you already trust rather than from a link in a message or a token that simply appeared in your wallet.
    • Cross-check the address against two independent sources, such as Etherscan and a listing on CoinGecko.
    • Treat any unexpected WETH that shows up in your wallet as suspect until you verify its contract.
    • Never approve spending for a token you reached through an unsolicited link.
    • Confirm the holder count and transfer history look consistent with a token used by hundreds of thousands of addresses.

    Lookalike addresses

    Scammers sometimes generate addresses that share the first and last few characters of the real one, counting on you to skim rather than read the whole string. Always compare the full address, not just its ends, and prefer the checksummed form so a wallet can flag a mismatch.

    Reading the WETH Contract On-Chain

    Beyond confirming the address, the explorer lets you read the live state of the contract, which is useful when you want to see exactly what backs the token you hold. The contract's ETH balance is its reserve, the total supply is the WETH in circulation, and the two track each other closely at all times. You can also read the published source to confirm that deposit() and withdraw() are the only functions that change supply, and that there is no owner function capable of minting WETH without locking ETH first. For a broad listing and market context, the WETH entry on CoinGecko links straight to the same verified contract address on each chain it supports.

    Checking the reserve yourself

    On the mainnet Etherscan page, the ETH balance shown for 0xC02aaA39b223FE8D0A0e5C4F27eAD9083C756Cc2 is the full backing for every WETH token. If that balance ever diverged from supply the token would be under- or over-collateralized, which the immutable contract design prevents by construction. Reading the reserve takes a few seconds and is the most direct way to confirm you are looking at the real WETH rather than a token that only borrowed the name.

    Frequently asked questions

    A closer look at the details.

    What is the WETH contract address on Ethereum?
    The canonical WETH contract address on Ethereum mainnet is 0xC02aaA39b223FE8D0A0e5C4F27eAD9083C756Cc2, the WETH9 contract deployed in 2017. It is an ERC-20 token with 18 decimals and has never changed.
    Is the WETH address the same on every chain?
    No. Each network runs its own WETH deployment at its own address — for example Arbitrum One uses 0x82aF49447D8a07e3bd95BD0d56f35241523fBab1, while Optimism and Base both use the predeploy 0x4200000000000000000000000000000000000006. Always match the address to the chain.
    How do I verify a WETH contract address?
    Open the address directly on the explorer for that chain, such as etherscan.io/token/ plus the address. Confirm the name reads Wrapped Ether, the decimals are 18, the source code is verified, and the contract holds an ETH reserve that matches the circulating supply.
    How do I add WETH to my wallet by address?
    Confirm your wallet's network, copy the matching WETH address, open Import tokens or Add custom token, paste the address, and let the wallet auto-fill the symbol WETH and 18 decimals. Your balance appears once it is added.
    Why does WETH need a contract at all?
    Native ETH does not implement the ERC-20 interface, so contracts that expect ERC-20 functions cannot handle it directly. The WETH contract wraps ETH one-for-one into a token form, letting it move through DeFi like any other ERC-20.
    Why is the WETH address written with mixed capital letters?
    The mixed case is an EIP-55 checksum that encodes verification bits in each letter's case, so a compatible wallet can catch a mistyped character. An all-lowercase version resolves to the same contract but carries no checksum protection.
    How can I tell a real WETH contract from a fake one?
    A genuine WETH page shows verified source code, hundreds of thousands of holders, heavy transfer history, and an ETH reserve matching supply. Cross-check the full address against two trusted sources such as Etherscan and CoinGecko, and ignore any WETH that arrives through an unsolicited link.
